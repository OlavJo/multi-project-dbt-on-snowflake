# Multiple native Snowflake dbt projects

Designed for an organisation that has adopted Snowflake and intends to use dbt across multiple independent analytics teams, without an additional dbt-Labs account. 

This repo documents a framework using Snowflake's own feature set (together with Snowflake embedded dbt (1.11+)) to replace key aspects of proprietary dbt-Labs functionality, particularly dbt Mesh and dbt Cloud.
